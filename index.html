These are the same .txt maps the Python environment loads from assets/main_levels/ and assets/gen_levels/, so anything you solve here is a level your agent will be graded on. You can only push crates, never pull them — a crate shoved into a corner is stuck for good, and that is exactly the situation the solver's deadlock check is built to avoid expanding.

About "par" and the solver

Par is the length of the solution found by the A* agent ported from agent_master.py: weighted A* with f = h + 0.5·g, a greedy nearest-goal Manhattan heuristic, and corner/wall deadlock pruning. It is a strong solution but not a proof of the optimum, so beating par is possible — and worth bragging about. Hint re-runs the search from wherever you are now, which is also how you find out you have pushed yourself into an unwinnable position.
